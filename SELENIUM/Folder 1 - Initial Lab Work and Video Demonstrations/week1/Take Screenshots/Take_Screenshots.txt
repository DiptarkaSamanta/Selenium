--------------------------------------------------------------------------------
1. OVERVIEW & IMPORTANCE OF SCREENSHOTS
--------------------------------------------------------------------------------
Capturing screenshots is an essential practice in web automation testing. 
Screenshots provide visual evidence of test execution, audit trails, and 
immediate diagnostic proof when automated test cases fail.

A. PRIMARY USE CASES:
   • Failure Debugging: Automatically capture web page state when assertions fail.
   • Audit & Compliance Reports: Maintain visual logs of successful workflow executions.
   • Visual Regression Testing: Compare UI layouts against baseline designs.

--------------------------------------------------------------------------------
2. METHODS TO TAKE SCREENSHOTS IN SELENIUM (PYTHON)
--------------------------------------------------------------------------------
Selenium WebDriver provides multiple built-in methods on the `driver` instance:

A. driver.save_screenshot(filename):
   • Saves full page screenshot directly to specified file path (.png).
   • Returns True if successful, False if error occurs.
   • Example: driver.save_screenshot("homepage.png")

B. driver.get_screenshot_as_file(filename):
   • Identical to save_screenshot; saves screenshot to target path.
   • Returns True on success, False on failure.
   • Example: driver.get_screenshot_as_file("./screenshots/error.png")

C. driver.get_screenshot_as_png():
   • Captures screenshot as binary PNG data in memory.
   • Useful for embedding screenshots in reports (HTMLTestRunner, Allure, PyTest HTML).
   • Example: binary_data = driver.get_screenshot_as_png()

D. driver.get_screenshot_as_base64():
   • Captures screenshot as Base64 encoded string.
   • Useful for inline HTML/JSON reporting or sending via REST API.
   • Example: b64_str = driver.get_screenshot_as_base64()

E. TAKING SCREENSHOT OF A SPECIFIC ELEMENT (SELENIUM 4+):
   • Individual WebElements also support save_screenshot.
   • Example:
     element = driver.find_element(By.ID, "logo")
     element.save_screenshot("logo.png")

--------------------------------------------------------------------------------
3. GENERIC REUSABLE METHOD TO TAKE SCREENSHOTS
--------------------------------------------------------------------------------
In real-world automation frameworks, screenshots should be handled dynamically with 
timestamped filenames, auto-created target directories, and reusable utility functions.

A. GENERIC UTILITY FUNCTION DESIGN:
   • Creates output folder if it doesn't exist.
   • Appends a unique date-timestamp (%Y%m%d_%H%M%S) to prevent overwriting.
   • Returns absolute path for integration into test reporting frameworks.

--------------------------------------------------------------------------------
4. COMPLETE PYTHON IMPLEMENTATION EXAMPLE
--------------------------------------------------------------------------------
from selenium import webdriver
from selenium.webdriver.common.by import By
import os
from datetime import datetime

def capture_screenshot(driver, test_name="screenshot"):
    folder_path = os.path.join(os.getcwd(), "screenshots")
    if not os.path.exists(folder_path):
        os.makedirs(folder_path)
    
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"{test_name}_{timestamp}.png"
    file_path = os.path.join(folder_path, filename)
    
    driver.save_screenshot(file_path)
    return file_path

# Driver Setup & Execution
driver = webdriver.Edge()
driver.maximize_window()

try:
    driver.get("https://testautomationpractice.blogspot.com/")
    
    # 1. Full Page Screenshot using generic method
    path = capture_screenshot(driver, "Homepage_Loaded")
    print("Screenshot saved to:", path)
    
    # 2. Element-level Screenshot
    logo = driver.find_element(By.CLASS_NAME, "titlewrapper")
    logo.save_screenshot("header_logo.png")
    print("Element screenshot saved to header_logo.png")

finally:
    driver.quit()
