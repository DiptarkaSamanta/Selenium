===============================================================================
           INTRODUCTION AND DIFFERENT FLAVORS OF SELENIUM
===============================================================================

1. WHAT & WHY SELENIUM
-------------------------------------------------------------------------------
What is Selenium?
  Selenium is an open-source automated testing suite specifically designed for 
  automating web applications across different web browsers and operating systems.

Why Selenium?
  • Open-Source & Free: No licensing fees; supported by a massive global community.
  • Multi-Language Support: Python, Java, C#, JavaScript, Ruby, Kotlin.
  • Multi-Browser Support: Chrome, Firefox, Edge, Safari, Opera.
  • Multi-Platform Support: Windows, macOS, Linux.
  • Ecosystem Integration: Works seamlessly with pytest, unittest, TestNG, JUnit, 
    Jenkins, GitHub Actions, and Docker.

-------------------------------------------------------------------------------
2. SELENIUM IDE & SELENIUM RC
-------------------------------------------------------------------------------
Selenium IDE (Integrated Development Environment):
  • Browser extension (Chrome, Firefox, Edge) providing record-and-playback.
  • Best for rapid test prototyping, reproducing bugs, and exporting test scripts.
  • Limited support for complex logic, dynamic wait handling, and parallel runs.

Selenium RC (Remote Control / Selenium 1):
  • Original flagship component before WebDriver.
  • Used a middleman proxy server to inject JavaScript into the browser.
  • Slower performance, complex setup, subject to Same-Origin Policy (SOP).
  • Deprecated and obsolete; superseded by Selenium WebDriver.

-------------------------------------------------------------------------------
3. SELENIUM WEBDRIVER
-------------------------------------------------------------------------------
What is Selenium WebDriver?
  Modern browser automation engine that controls web browsers natively by 
  communicating directly with browser engine drivers without injecting JavaScript.

Architecture & Workflow:
  1. Test Script (Python/Java/C#)
  2. W3C WebDriver Protocol (HTTP/JSON API standard)
  3. Browser Driver (ChromeDriver, GeckoDriver, etc.)
  4. Web Browser (Chrome, Firefox, Edge, Safari)

Key Features:
  • Direct Native Control: Accurate and realistic user simulation.
  • Advanced Controls: Handles dynamic web elements, alerts, frames, pop-up windows, 
    and explicit/implicit waits.

-------------------------------------------------------------------------------
4. SELENIUM GRID
-------------------------------------------------------------------------------
What is Selenium Grid?
  Distributed test execution engine for running test suites in parallel across 
  multiple machines, operating systems, and browsers simultaneously.

Why Use Grid?
  • Parallel Execution: Cuts down execution time significantly.
  • Cross-Browser & Multi-OS Matrix: Runs tests on combinations like 
    Windows/Chrome, macOS/Safari, and Linux/Firefox at the same time.

Architecture:
  • Grid 3: Hub & Node architecture (Hub routes commands to worker Nodes).
  • Grid 4: Modern microservices architecture (Router, Distributor, Session Queue, 
    Node, Event Bus) with native Docker container support.
