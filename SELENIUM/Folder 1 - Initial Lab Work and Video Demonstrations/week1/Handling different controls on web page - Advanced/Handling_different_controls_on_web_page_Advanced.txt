1. HANDLING ALERT BOX
--------------------------------------------------------------------------------
JavaScript popups/alerts interrupt DOM execution and must be handled using 
Selenium's `switch_to.alert` interface.

A. TYPES OF ALERTS:
   1. Simple Alert: Displays a message with an 'OK' button.
   2. Confirm Alert: Displays a message with 'OK' and 'Cancel' buttons.
   3. Prompt Alert: Displays a text input box with 'OK' and 'Cancel' buttons.

B. SYNTAX & METHODS:
   • Switch to alert:    alert = driver.switch_to.alert
   • Get alert message:  message = alert.text
   • Accept (Click OK):   alert.accept()
   • Dismiss (Cancel):   alert.dismiss()
   • Send text (Prompt): alert.send_keys("text_value")

C. CODE EXAMPLE:
   driver.find_element(By.ID, "alertbtn").click()
   alert = driver.switch_to.alert
   print("Alert Text:", alert.text)
   alert.accept()

2. HANDLING DATEPICKER
--------------------------------------------------------------------------------
Datepickers allow users to select dates either via direct input typing or by 
navigating a calendar widget.

A. METHOD 1: DIRECT INPUT TYPING (Preferred if input field is editable)
   date_field = driver.find_element(By.ID, "txtDate")
   date_field.clear()
   date_field.send_keys("16/09/2026")

B. METHOD 2: CALENDAR WIDGET NAVIGATION (Using Loops or Select class)
   # Step 1: Open calendar
   driver.find_element(By.ID, "txtDate").click()
   
   # Step 2: Select Month & Year via Select class or loop navigation
   month_dropdown = Select(driver.find_element(By.XPATH, "//select[@class='ui-datepicker-month']"))
   month_dropdown.select_by_visible_text("Sep")
   
   year_dropdown = Select(driver.find_element(By.XPATH, "//select[@class='ui-datepicker-year']"))
   year_dropdown.select_by_visible_text("2026")
   
   # Step 3: Select target day
   driver.find_element(By.XPATH, "//a[@data-date='16']").click()

3. HANDLING FILE UPLOAD
--------------------------------------------------------------------------------
HTML file input fields (`<input type="file">`) can be automated directly using 
`send_keys()` without needing third-party GUI automation tools.

A. SYNTAX:
   file_input = driver.find_element(By.XPATH, "//input[@type='file']")
   file_input.send_keys("C:/path/to/your/file.txt")

B. IMPORTANT NOTES:
   • Provide the absolute local file path.
   • Do NOT click the file upload button first, as native OS file dialogs block Selenium. 
     Simply send the file path directly to the `<input type="file">` element.

4. HANDLING MULTIPLE WINDOWS / TABS
--------------------------------------------------------------------------------
When a click opens a new browser window or tab, Selenium remains focused on the 
original window until explicitly switched using window handles.

A. WINDOW HANDLE CONCEPTS:
   • Current Window Handle: `driver.current_window_handle`
   • All Window Handles:    `driver.window_handles` (returns list of unique IDs)

B. SYNTAX & SWITCHING LOGIC:
   parent_window = driver.current_window_handle

   # Click link that opens new tab/window
   driver.find_element(By.ID, "openwindow").click()

   all_windows = driver.window_handles

   for handle in all_windows:
       if handle != parent_window:
           driver.switch_to.window(handle)
           print("Switched to Child Window:", driver.title)
           # Perform operations on child window...
           driver.close() # Close child window

   # Switch back to parent window
   driver.switch_to.window(parent_window)

5. WORKING WITH KEYBOARD EVENTS
--------------------------------------------------------------------------------
Keyboard shortcuts (Ctrl+A, Ctrl+C, Ctrl+V, ENTER, TAB) are executed using 
Selenium's `ActionChains` or `Keys` class.

A. IMPORT REQUIREMENTS:
   from selenium.webdriver.common.keys import Keys
   from selenium.webdriver.common.action_chains import ActionChains

B. COMMON KEYPRESSES (Direct send_keys):
   input_element.send_keys("Search Text", Keys.ENTER)
   input_element.send_keys(Keys.TAB)

C. COMBINATION KEYS (ActionChains):
   actions = ActionChains(driver)

   # Select All (Ctrl + A)
   actions.key_down(Keys.CONTROL).send_keys("a").key_up(Keys.CONTROL).perform()

   # Copy (Ctrl + C)
   actions.key_down(Keys.CONTROL).send_keys("c").key_up(Keys.CONTROL).perform()

   # Paste (Ctrl + V)
   actions.key_down(Keys.CONTROL).send_keys("v").key_up(Keys.CONTROL).perform()

6. WORKING WITH SCROLLBAR
--------------------------------------------------------------------------------
Selenium handles scrolling by executing JavaScript via `driver.execute_script()`.

A. SCROLL BY PIXEL OFFSET:
   driver.execute_script("window.scrollBy(0, 500);") # Scroll down 500px

B. SCROLL TO BOTTOM OF PAGE:
   driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")

C. SCROLL TO SPECIFIC ELEMENT (Scroll into View):
   target_element = driver.find_element(By.ID, "mousehover")
   driver.execute_script("arguments[0].scrollIntoView(true);", target_element)


--------------------------------------------------------------------------------
7. WORKING WITH DRAG AND DROP
--------------------------------------------------------------------------------
Drag and drop operations require moving an element from a source location to 
a target container using `ActionChains`.

A. IMPORT REQUIREMENT:
   from selenium.webdriver.common.action_chains import ActionChains

B. SYNTAX METHOD 1 (Direct drag_and_drop):
   source = driver.find_element(By.ID, "draggable")
   target = driver.find_element(By.ID, "droppable")

   actions = ActionChains(driver)
   actions.drag_and_drop(source, target).perform()

C. SYNTAX METHOD 2 (Step-by-Step Click, Hold & Move):
   actions.click_and_hold(source).move_to_element(target).release().perform()


--------------------------------------------------------------------------------
8. HANDLING IFRAMES
--------------------------------------------------------------------------------
An iframe (`<iframe>`) is an HTML document embedded inside another HTML document. 
Elements inside an iframe cannot be accessed until switching driver context into it.

A. SWITCHING INTO IFRAME:
   • By ID or Name:   driver.switch_to.frame("iframe-name-or-id")
   • By Index:        driver.switch_to.frame(0)
   • By WebElement:   iframe_elem = driver.find_element(By.ID, "courses-iframe")
                      driver.switch_to.frame(iframe_elem)

B. SWITCHING BACK TO MAIN PAGE:
   • To Parent Frame:    driver.switch_to.parent_frame()
   • To Default Content: driver.switch_to.default_content()

9. FIND THE STATE OF A WEB ELEMENT (DISABLED AND ENABLED)
--------------------------------------------------------------------------------
Checking an element's operational state prevents `ElementNotInteractableException`.

A. METHODS:
   • Is Displayed (Visible on page):   element.is_displayed() # True/False
   • Is Enabled (Interactive state):   element.is_enabled()   # True/False
   • Is Selected (Checkbox/Radio):     element.is_selected()  # True/False

B. CODE EXAMPLE:
   btn = driver.find_element(By.ID, "submit")
   if btn.is_displayed():
       if btn.is_enabled():
           print("Element is active and ready to be clicked.")
       else:
           print("Element is disabled / non-clickable.")


--------------------------------------------------------------------------------
10. GET THE TEXT ON ELEMENT, GET VALUE OF ELEMENT ATTRIBUTE
--------------------------------------------------------------------------------
Extracting textual content and HTML attributes from DOM nodes.

A. GET TEXT ON ELEMENT:
   • Retrieves inner visible text between opening and closing tags (<p>Text</p>).
   • Syntax: element_text = element.text

B. GET VALUE OF ELEMENT ATTRIBUTE:
   • Retrieves value of any HTML attribute (href, value, class, src, id, name).
   • Syntax: attribute_val = element.get_attribute("attribute_name")

C. EXAMPLES:
   # Inner Text
   header_text = driver.find_element(By.TAG_NAME, "h1").text
   print("Header:", header_text)

   # Input Field Value
   input_val = driver.find_element(By.ID, "name").get_attribute("value")
   
   # Image Source URL
   img_src = driver.find_element(By.TAG_NAME, "img").get_attribute("src")
   
   # Link Target URL
   link_url = driver.find_element(By.LINK_TEXT, "Home").get_attribute("href")
