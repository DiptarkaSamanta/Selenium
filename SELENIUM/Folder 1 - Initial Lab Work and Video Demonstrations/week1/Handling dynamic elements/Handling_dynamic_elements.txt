--------------------------------------------------------------------------------
1. OVERVIEW OF DYNAMIC ELEMENTS & WEBTABLES
--------------------------------------------------------------------------------
Dynamic elements are HTML components whose properties (such as text, IDs, or row 
counts) change dynamically during runtime based on user interaction or backend data.

A WebTable is an HTML element represented by the `<table>` tag, composed of:
  • `<table>`  - Defines the HTML table container.
  • `<thead>`  - Table header container.
  • `<tbody>`  - Table body container.
  • `<tr>`     - Table row.
  • `<th>`     - Table header cell.
  • `<td>`     - Table data cell.


--------------------------------------------------------------------------------
2. WORKING WITH WEBTABLE
--------------------------------------------------------------------------------
Before traversing a table, common table metrics (total rows, total columns, 
and header titles) must be identified.

A. COUNT TOTAL ROWS IN A WEBTABLE:
   rows = driver.find_elements(By.XPATH, "//table[@id='product']//tr")
   total_rows = len(rows)
   print("Total Rows:", total_rows)

B. COUNT TOTAL COLUMNS IN A WEBTABLE:
   cols = driver.find_elements(By.XPATH, "//table[@id='product']//tr[1]/th")
   total_cols = len(cols)
   print("Total Columns:", total_cols)

C. GET SPECIFIC CELL DATA (Row 'r', Column 'c'):
   row_num = 3
   col_num = 2
   cell_xpath = f"//table[@id='product']//tr[{row_num}]/td[{col_num}]"
   cell_data = driver.find_element(By.XPATH, cell_xpath).text
   print(f"Data at Row {row_num}, Column {col_num}:", cell_data)


--------------------------------------------------------------------------------
3. TRAVERSING THROUGH WEBTABLE
--------------------------------------------------------------------------------
Traversing involves systematically iterating through all rows and columns to 
search, validate, or aggregate data.

A. ITERATING OVER ENTIRE TABLE DATA:
   # Loop through each row
   for r in range(2, total_rows + 1):  # Starting from 2 to skip header row
       row_data = []
       for c in range(1, total_cols + 1):
           cell_value = driver.find_element(
               By.XPATH, f"//table[@id='product']//tr[{r}]/td[{c}]"
           ).text
           row_data.append(cell_value)
       print(f"Row {r}:", row_data)

B. CONDITIONAL SEARCH & ACTION IN WEBTABLE:
   Example: Find the instructor named "Rahul Shetty" and print their course price.

   for r in range(2, total_rows + 1):
       instructor = driver.find_element(
           By.XPATH, f"//table[@name='courses']//tr[{r}]/td[1]"
       ).text
       
       if instructor == "Rahul Shetty":
           course_title = driver.find_element(
               By.XPATH, f"//table[@name='courses']//tr[{r}]/td[2]"
           ).text
           price = driver.find_element(
               By.XPATH, f"//table[@name='courses']//tr[{r}]/td[3]"
           ).text
           print(f"Course: {course_title} | Price: {price}")

C. AGGREGATING / SUMMING NUMERIC COLUMNS:
   Example: Calculate total price sum of all courses in the table.

   total_price = 0
   for r in range(2, total_rows + 1):
       price_text = driver.find_element(
           By.XPATH, f"//table[@name='courses']//tr[{r}]/td[3]"
       ).text
       total_price += int(price_text)

   print("Calculated Total Price Sum:", total_price)
