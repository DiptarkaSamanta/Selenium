================================================================================
    SELENIUM WEBDRIVER - SYNCHRONIZATION AND WAIT TYPES
================================================================================

--------------------------------------------------------------------------------
1. WHY SYNCHRONIZATION?
--------------------------------------------------------------------------------
Synchronization in Selenium is the technique of aligning script execution speed 
with the rendering speed of the web application.

A. THE PROBLEM:
   • Execution Speed vs Rendering Speed: Python code executes instructions in 
     milliseconds, whereas web browsers rely on server response times, AJAX calls, 
     asynchronous JavaScript rendering, and dynamic DOM updates.
   • Exception Failures: Interacting with elements before they are loaded or 
     ready leads to runtime exceptions:
     - NoSuchElementException: Element is not yet in the HTML DOM.
     - ElementNotInteractableException / ElementNotVisibleException: Element is in 
       DOM but not visible or disabled.
     - StaleElementReferenceException: DOM was updated and old reference is lost.

B. WHY AVOID time.sleep()?
   • Hardcoded/Static Wait: Pauses execution for a fixed duration regardless of 
     actual load time (e.g., waiting 5 seconds when an element loads in 0.5 seconds).
   • Slow Test Suites: Unnecessarily inflates total test execution time.
   • Unreliable: If page takes longer than the hardcoded sleep duration, test fails.

--------------------------------------------------------------------------------
2. IMPLICIT WAIT
--------------------------------------------------------------------------------
Implicit Wait specifies a global default wait time for the WebDriver instance to 
poll the DOM when searching for any element.

A. KEY CHARACTERISTICS:
   • Scope: Applies globally to all find_element and find_elements calls throughout 
     the driver lifecycle.
   • Dynamic Polling: Continuously checks the DOM at intervals until the element is 
     found or timeout expires.
   • Default Timeout: 0 seconds (until explicitly configured).

B. SYNTAX (PYTHON):
   driver.implicitly_wait(10)  # Time specified in seconds

C. ADVANTAGES & DISADVANTAGES:
   • Advantages: Simple to declare once at script initialization.
   • Disadvantages: Only checks presence in the DOM (does not verify visibility, 
     clickability, or enablement). Can obscure timing issues or conflict with 
     explicit waits.

D. CODE EXAMPLE:
   from selenium import webdriver
   from selenium.webdriver.common.by import By

   driver = webdriver.Edge()
   driver.implicitly_wait(10)  # Global wait of 10 seconds

   driver.get("https://testautomationpractice.blogspot.com/")
   element = driver.find_element(By.ID, "name")
   element.send_keys("Test User")

--------------------------------------------------------------------------------
3. EXPLICIT WAIT
--------------------------------------------------------------------------------
Explicit Wait is a conditional, targeted wait that halts execution until a specific 
Expected Condition is satisfied for a specific web element before timing out.

A. KEY CHARACTERISTICS:
   • Scope: Applied only to specified element(s) and specific conditions.
   • Intelligent & Flexible: Evaluates specific state flags (visible, clickable, 
     text present, selected).
   • Polling Interval: Repeatedly checks the condition (default poll rate: 500 ms).

B. REQUIRED MODULE IMPORTS:
   from selenium.webdriver.support.ui import WebDriverWait
   from selenium.webdriver.support import expected_conditions as EC
   from selenium.webdriver.common.by import By

C. COMMON EXPECTED CONDITIONS (EC):
   • EC.presence_of_element_located((By..., "..."))      - Element exists in DOM
   • EC.visibility_of_element_located((By..., "..."))    - Element in DOM and visible
   • EC.element_to_be_clickable((By..., "..."))          - Element visible and enabled
   • EC.text_to_be_present_in_element((By..., "..."), "text") - Text present in element
   • EC.invisibility_of_element_located((By..., "..."))  - Element disappears/hidden

D. CODE EXAMPLE:
   wait = WebDriverWait(driver, 10)  # Timeout of 10 seconds

   # Wait until search button is clickable
   search_btn = wait.until(EC.element_to_be_clickable((By.ID, "search-btn")))
   search_btn.click()

--------------------------------------------------------------------------------
4. KEY DIFFERENCES SUMMARY
--------------------------------------------------------------------------------
--------------------------------------------------------------------------------
Feature                 Implicit Wait               Explicit Wait
--------------------------------------------------------------------------------
Scope                   Global (All elements)       Specific Element & Condition
Condition Check         DOM Presence Only           Custom (Visible, Clickable, etc.)
Declaration             Declared once               Used wherever required
Flexibility             Low                         High
Industry Standard       Basic Safety Net            Recommended Best Practice
